# User Access Management System (LabVIEW + QR)

A showcase project of a complete User Access Management System, designed and developed from scratch using LabVIEW.  
This project demonstrates secure authentication, user-friendly onboarding, and role-based access control—with QR code integration as an innovative authentication option.

## 🗝️ Key Features Demonstrated

- **Dual authentication:** Login using either username/password or your unique auto-generated QR code (via webcam)
- **Role-Based Access Control:**
  - **User:** Access and manage personal data
  - **Admin:** Full dashboard for Create, Read, Update, Delete (CRUD) operations on all users
- **Advanced admin search:** Look up users by either username or QR code
- **Smooth and secure user onboarding:** With robust validation
- **All data safely stored** in a CSV file, with password encryption
